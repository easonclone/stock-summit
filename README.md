# 股市攻頂戰 Stock Summit

一款純前端像素風回合制策略遊戲。從潘大帥、尤尤、老伯、張婷選一位參賽，與三位電腦對手在同一張分岔路線圖上規劃路線，15 個交易日後收盤，「層數＋鈔票加成」最高者勝出。所有新聞與市場效果都是虛構遊戲情境。

## 線上遊玩

**👉 https://easonclone.github.io/stock-summit/**

開啟網址即可在瀏覽器遊玩，無須安裝。支援桌機鍵盤、滑鼠與手機直向觸控。

## 本機啟動

建議使用 Node.js 22。第一次開啟先安裝鎖定的相依套件，再執行開發伺服器。

```sh
npm ci
npm run dev
```

在瀏覽器打開終端機列出的網址，選擇「開始遊戲」。設定頁可調整電腦難度、漲跌配色、震動與音效。

| 操作 | 按鍵 |
| --- | --- |
| 切換可前往的節點 | ← →（或 A、D），或直接點節點 |
| 確認進場 | Enter、空白鍵，或「確認進場」按鈕 |
| 使用卡片 | 1、2、3，或點選卡片 |

## 玩法

- **路線圖**：15 列 × 4 路，由下往上，每列一個交易日。每天只能走進與目前節點相連的下一列節點。四人同時選擇、同時結算，沒有時間壓力。
- **節點**：穩健持有（+2 層）、槓桿加碼（+4 層，但下一次市場利空跌幅加倍）、獲利了結（不爬升，入帳 150 元）、問號卡箱（+1 並抽卡）、研究報告（+1 並取得下一次市場預告）、抄底補給（+1，落後者可抽補給卡）、場外觀望（+1）。
- **市場事件**：每 3 個交易日發生一次虛構事件，可能讓全體或特定名次上升、下滑或停牌。停牌期間進入的節點沒有效果。避險卡可抵銷一次利空，停損卡限制下滑層數。
- **卡片**：卡欄最多 3 張，於確認進場前使用。做空卡會鎖定前方最近的對手；前方沒有對手時卡片保留。
- **收盤**：分數＝實際層數＋鈔票加成（每 100 元 1.2 層，上限 3 層），同分時以實際層數優先。

## 開發與建置

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Vite 會在 `dist/` 產生靜態檔案。正式產物使用相對資源路徑，可部署到 GitHub Pages 的 `/stock-summit/` 子路徑。推送到 `main` 後，`.github/workflows/deploy.yml` 會自動執行型別檢查、測試與建置，並部署到 GitHub Pages。

| 目錄 | 職責 |
| --- | --- |
| `src/data/` | 角色、市場事件、卡片、效果、山路地圖與市場狀態 |
| `src/config/` | 回合數、節點類型、鈔票加權、電腦難度、配色和啟動資料檢查 |
| `src/core/` | 路線圖生成與驗證、回合結算、共用效果引擎、層數換算、種子亂數 |
| `src/scenes/` | Phaser 山路畫面與升降動畫 |
| `src/ui/` | 路線圖介面、結算、音效與程式化像素素材 |
| `tests/` | 資料驗證、路線圖、節點、卡片、事件、完整賽局與平衡測試 |

新增或調整節點、卡片、市場事件時，在 JSON 指定 `effectIds` 即可，遊戲在啟動時檢查引用。像素素材集中在 `src/ui/pixels.ts`。

## 設計假設與待驗證項目

- 取消競速：不再比先登頂，40 層山頂只是上限。移除練習場、暫停、開局倒數、巡邏散戶、墜落交易員與觸控方向鍵。
- 電腦以「層數、鈔票、卡片與預告價值－槓桿風險＋看一步」評分選路；難度只影響隨機雜訊與用卡機率。
- 「再玩一局」沿用原種子；「新賽道」換新種子。以 `?seed=3708` 這類查詢參數可指定種子，相同選擇可重現整局。
- 平衡為模擬初版（固定路線勝率約 13–15%，依價值規劃約 29–35%），尚待真人多局測試。
