# 股市攻頂戰 Stock Summit

一款純前端像素風垂直競速遊戲。從潘大帥、尤尤、老伯、張婷選一位參賽，與三位電腦對手走過鈔票、梯子與金磚，搶先登頂。所有新聞與市場效果都是虛構遊戲情境。

## 線上遊玩

**👉 https://easonclone.github.io/stock-summit/**

開啟網址即可在瀏覽器遊玩，無須安裝。支援桌機鍵盤與手機觸控。

## 本機啟動

建議使用 Node.js 22。第一次開啟先安裝鎖定的相依套件，再執行開發伺服器。

```sh
npm ci
npm run dev
```

在瀏覽器打開終端機列出的網址，選擇「開始遊戲」。可在設定切換 40 層預設賽道與 10 層練習場，並調整電腦難度、漲跌配色與事件震動。

| 操作 | 按鍵 |
| --- | --- |
| 左右移動及梯子上、下 | 方向鍵或 WASD |
| 跳躍 | 空白鍵 |
| 使用卡片 | 1、2、3，或點選卡片 |
| 暫停或繼續 | Escape |
| 觸控裝置 | 遊戲下方的方向及跳躍按鈕 |

## 路線、盤勢與落後補給

- 梯子分布在左、中、右側，各層的平台長度、跳台和卡箱位置不同。巡邏散戶會在部分樓層的移動路線上來回行走，可以跳過或等它經過。碰撞停頓 1 秒，同一次持續接觸只觸發一次；玩家和電腦對手適用相同規則。
- 多頭讓角色移動加快 12%，散戶巡邏降至 80%。空頭則讓角色移動減慢 8%，散戶巡邏提升至 124%。這些倍率可在市場狀態資料調整。
- 三格卡位有空就能連續拾取不同卡箱。每個卡箱各自約 20 秒重生。只有排名後兩位且落後領先者至少 2 層的選手能開綠色補給箱。補給箱可能開出專屬的「抄底補給」，可反彈 1 層並獲得一次市場避險。
- 墜落交易員每波結束後等 4–7 秒再出現，約六成波次會同時警示兩個落點。命中後停頓 1 秒。玩家與電腦選手可離開落點閃避。
- 「市場流動性危機」會讓手持至少 100 元的選手扣除 100 元，金額不足者停頓 2 秒。避險基金可抵銷該次事件，扣款後的剩餘金額才用於收盤加權。
- 即時交易回報顯示出手者、對象和實際效果。收盤看板以近一個事件週期的登山進度差，呈現末段漲跌的百分點變化。

## 鈔票與收盤

- 綠色綁帶鈔票顯示面額。每位選手可各拾一次，累計金額會在收盤時自動加權。
- 第一位抵達山頂後開始 10 秒倒數，倒數期間可繼續攀爬、用卡或拾取鈔票。若一直無人登頂，達到 6 分鐘就收盤。
- 最終分數為實際層數（包含層與層之間的進度）加上鈔票加成。收集每 100 元換算 1.2 層，主賽道最多 3 層，練習場最多 1 層。同分時以實際高度優先。
- 淺藍色懸空方塊可以作為兩段跳的中繼點，部分方塊放有卡箱。卡箱依身體碰撞拾取，靠近且受限時會顯示卡槽已滿或補給資格。卡片音效與震動皆可在設定切換。

## 開發與建置

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Vite 會在 `dist/` 產生靜態檔案。正式產物使用相對資源路徑，可部署到 GitHub Pages 的 `/stock-summit/` 子路徑，由瀏覽器執行完整遊戲。推送到 `main` 後，`.github/workflows/deploy.yml` 會自動執行型別檢查、測試與建置，並部署到 GitHub Pages。

| 目錄 | 職責 |
| --- | --- |
| `src/data/` | 角色、市場事件、卡片、效果、地圖、障礙物與市場狀態 |
| `src/config/` | 賽局、物理、鈔票加權、難度、配色和啟動資料檢查 |
| `src/core/` | 固定步長賽局、移動與碰撞、電腦對手、排名、鈔票拾取、種子亂數、地形及共用效果 |
| `src/scenes/` | Phaser 畫布、垂直鏡頭、像素場景及效果呈現 |
| `src/ui/` | 鍵盤、介面、角色、卡片和首頁的程式化像素素材 |
| `tests/` | 資料驗證、移動、電腦到頂、排名與效果測試 |

調整既有卡片或市場事件時，從 JSON 指定 `effectIds`。遊戲在啟動時檢查引用、落點和地圖路徑。像素素材集中在 `src/ui/pixels.ts`，角色的 `spriteKey` 與 `portrait` 欄位可作為未來接入正式素材的對應鍵。

## 設計假設與待驗證項目

- 40 層主賽道另有第 0 層起跑區。平台採單向碰撞，跳躍可從下方穿過。部分高度差只適合走梯子。觸及終點平台會開始收盤倒數。
- 市場事件每 15 秒觸發，未登頂時最長開盤 6 分鐘，卡箱約 20 秒重生。預設間隔一個市場回合才會再次抽到負面事件，事件池全為負面時允許繼續抽取。電腦難度只調整反應時間與選路傾向。
- 「再玩一局」沿用原賽局種子與設定。以 `?seed=3708` 這類查詢參數可指定種子；選角、難度、地圖和輸入相同時可重現事件抽取與墜落預警。
- 位置交換卡依原規格延後。現階段使用純程式化像素素材，設定保留至本次頁面關閉。尚待真人多局測試主賽道節奏、補給反超率及實機觸控體驗。
