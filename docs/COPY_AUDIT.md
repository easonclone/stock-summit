# 玩家文案比較

| 原始文字 | 理解障礙 | 新版玩家先看到 | 程式位置 |
| --- | --- | --- | --- |
| 配置資金、以淨資產決勝 | 缺少第一步操作 | 選牌、挑路線，收盤比總身家；首次操作另有白話說明 | `src/ui/trading-terminal.ts` 首頁 |
| 須符合融資條件並完成借款 | 玩家必須自行猜條件 | 搭配「開槓桿」即可使用；借不到時直接說明；選路後顯示估計金額 | `src/core/trading-effects.ts`、`src/ui/trading-terminal.ts` 手牌 |
| 投資部位／符合條件損失 | 看不出現在有沒有股票、護盾還能不能加 | 手上沒有股票、護盾已滿、利空情境下可少賠多少 | 同上 |
| 額外持倉報酬率、協同效應 | 看不出這筆交易值多少 | 估計多賺多少元，百分比與百分點放進細節 | `src/core/trade-preview.ts`、`src/ui/trading-terminal.ts` |
| 替換既有卡片 | 沒說接下來要點哪裡 | 點選要換掉的牌，或直接丟新卡 | `src/ui/trading-terminal.ts` 抽換牌 |
| 自有投入、新增融資、預估負債變動、估計處分 | 充滿零值和抽象欄位 | 自己出、向券商借、賣股還款；有實際數值才顯示 | `src/ui/trading-terminal.ts` 下單預覽 |
| 融資比率逼近追繳門檻 | 不知道為何要補錢 | 借款快追上股票市值，再跌可能得補錢 | `src/core/economy.ts` |
| 部位處分、增量損失、帳務先列 | 無法先知道發生了什麼 | 先講賣了多少股票、還了多少、花了多少，再展開看帳目 | `src/ui/crisis-dialog.ts` |
| 持倉承壓 | 看不出誰受到影響、自己賺賠多少 | 新聞下方直接列本人損益和護盾擋下的金額 | `src/ui/trading-terminal.ts` 快訊 |
| 資訊列與已公開路線 | 不清楚哪條路可走 | 亮框是今天可以走的路；色點是大家走過的路 | `src/ui/route-map.ts` |
| 顯示與音效設定、結算動畫 | 不易理解操作結果 | 切換綠漲紅跌、直接看結算、播放交易音效 | `src/main.ts` |
| 投資績效明細、最大回撤 | 看不懂戰績如何比較 | 先看總身家排行，再展開最大跌幅與帳務明細 | `src/ui/settlement.ts` |
