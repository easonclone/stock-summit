# 遊戲用語

首頁先交代下單和勝利條件。交易席位、手牌、新聞和節點先顯示短標題及白話後果；精確數值、出手條件與例外放在展開區。角色反應可以有股市梗，涉及損失時先講結果。

| 明細用語 | 畫面用語 |
| --- | --- |
| 淨資產 | 總身家 |
| 可用現金 | 手上現金 |
| 投資部位市值 | 股票市值 |
| 融資負債 | 借款 |
| 紓困負債 | 救命貸款 |
| 投資報酬率 | 總報酬 |
| 最大回撤 | 最大跌幅 |
| 卡片協同 | 卡片連招 |
| 確認交易 | 確定下單 |
| 投資績效報告 | 本局戰績 |

追繳、強制平倉與定存保留台股術語並加一句解釋。借款警示只在有融資風險時顯示；資產過低及重整限制各自說明。新聞標題、副標與效果分開呈現，全數標示為虛構。金額、百分比、天數及觸發門檻由實際設定或結算資料輸出。

盤點範圍包含首頁、選角、新手說明、顯示設定、四人交易席、路線圖、手牌、抽換牌、快訊及預告、下單預覽、收盤與分享、初始化失敗及各種財務危機。
