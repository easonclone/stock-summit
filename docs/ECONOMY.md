# 經濟、風控及破產規則

所有金額為整數遊戲元。交易資金每人同額，初始本金預設 $10,000。JSON 設定參數供調校，畫面與電腦讀取同一套規則。

## 資產與負債

- 淨資產為現金、投資部位市值與定存本金總和，減去融資、紓困負債。報酬率以相對本金的淨資產變化計算。
- 自有資金買進時由現金移入部位。融資本金同時增加部位市值與融資負債。正的開辦費率及融資日息至少入帳 1 元，利息不足即併入融資負債。每日按日終融資餘額計息。
- 定存以批次保存本金與到期日。從下一交易日起，每日按原始本金領息，期滿返還本金。收盤時尚未到期的本金計入資產，未經過的天數不計息。
- 賣出按現有部位市值處分。清償等額扣減現金與負債，融資先於紓困。股息與現金收益入現金帳，盤中及市場漲跌進入部位帳，均各記一次。
- 可借款金額同時受現金、自有資金、淨資產、總債務及擔保比率限制。下單時把開辦費列入可借額的計算；買進後的市場變化可能讓實際曝險超過初始上限。
- 單局只有一個合併部位。買進後盤中波動作用於整個部位，槓桿收益與虧損按相同的部位基數計算。平倉費之外，市場下跌造成的損失在重估時已經入帳。

## 追繳與強制平倉

- 財務警戒由淨資產、融資比率或現金緩衝觸發，限制新增融資。既有擔保、變現還款及交易規則仍有效。
- 融資比率為融資負債除以投資部位市值。有債且部位為零時視為無可擔保部位。達追繳門檻後，計算恢復到維持目標所需金額，優先用現金補繳。
- 現金不足時，現有部位全數處分並扣除平倉費，淨所得優先清償融資。短缺繼續列為融資負債，並用實際淨資產判斷是否破產。
- 市場流動性危機等事件可以透過共用效果降低單日追繳門檻。避險按取得順序抵銷下一次符合條件的市場事件損失；盤中路線波動與費用照常入帳。

## 破產、重整與最後收盤

- 必要的損益、融資利息、收盤費與追繳處理完成後，淨資產小於等於零即破產。首度破產且仍有後續交易日者，可接受一次重整。電腦使用相同重整帳務。
- 重整處分剩餘部位與定存，使用所得及既有現金，依序清償舊融資、舊紓困。剩下的舊債明列減免。手牌、保護與市場預告一起清除。
- 預設以 $2,000 現金和 $1,500 紓困負債重開，即時淨資產為 $500。另有 $500 收盤費先列應付，最後一天正式轉入紓困負債；若提早出局，於個人最終結算列入。重整後兩個交易日禁止新增槓桿，低淨資產警戒可能延長實際限制。
- 重整只在當日破產判定之後執行，同一筆結算無第二次判定。第二次破產或收盤日破產即出局，保留資產負債與逐日紀錄，停止抽卡、交易與市場影響。
- 收盤按仍有效席位的最終淨資產排名，同分並列。全員出局時收盤且無冠軍。最高資產和最大回撤採逐日收盤，另計入破產時淨資產低點。
