# 經濟與歸零規則（V3.1）

所有金額為整數遊戲元。每人起手 $10,000。數值放在 `src/config/financial.json`、`src/config/allocation.json`、`src/config/settlement.json`、`src/config/shop.json`、`src/data/finance.json` 與 `src/data/cards.json`，畫面、電腦與模擬都讀同一套規則（`src/core/settlement.ts`）。

## 兩種錢

- **現金**：不受股市漲跌影響。現金奶牛這類王牌會讓現金每天變多；商店日可以用來買王牌與道具。
- **股票**：跟著每日共同市場與新聞漲跌。
- **總身家 = 現金 + 股票。** 沒有借款、還款、利息、開辦費、收盤另付、定存或追繳。

## 每日配置

- 只有三種配置：全留現金（0%）、一半買股（50%）、全部買股（100%）。預設沿用前一天，第一天為一半買股。
- 配置在市場結果揭曉前與卡片一起鎖定，之後無法撤回。
- 調整配置只是現金與股票互換：股票目標 = ⌊總身家 × 比例⌋，沒有手續費，總身家不變。
- 股票最多跌到 $0，不會變成負值或欠款。

## 結算順序

1. 鎖定四人的配置與道具。
2. 依配置換成股票與現金；立即型道具（拿現金、領股票的 5%、東山再起）。
3. 共同市場：所有人同一個漲跌幅（`market_day`，目前 −4.5%～+5.5%，同日共用一個種子亂數）；新聞日再加上新聞漲跌（只算新聞打到的人）。兩者合起來是基礎股票損益。
4. 股票有賺：百分比加成先相加，再依序乘特殊倍率，最後不超過基礎獲利的 5 倍（`settlement.maxGainMultiplier`）。
5. 股票有賠：賭神、瘋狂加碼先放大（股票最多賠到 $0），再由防彈衣與一個待命護盾少賠，合計最多 80%（`settlement.maxLossCut`）；逃過一劫擋固定金額，反向操作把虧損翻成獲利，上限 $2,000。每次賠錢只用掉一個護盾。
6. 對手狙擊：目標股票少 5%，同一人每天最多一次（`settlement.attacksPerTarget`）。
7. 固定現金收入，不再放大：現金奶牛（每天最多 $300，銀行大戶讓它加倍）、股息王、空軍司令、印鈔機、華爾街之狼、長期持有。
8. 收盤：逆風飛翔、總身家 ≤ 0 即歸零、排名。

每一步都寫進當日紀錄，所有步驟加總正好等於總身家變化。不同角色的損益差異只來自持股金額、王牌、道具以及新聞目標。

## 歸零與翻身

- 第一次歸零且還有後續交易日：拿 $1,000 翻身資金，不用還。王牌保留；道具、護盾與新聞情報清空，避免刻意歸零換資源。
- 第二次歸零或最後一日歸零：出局，可觀戰或查看個人結算。
- 賭神與瘋狂加碼會放大虧損，全部買股時偶爾會歸零（1,000 種子模擬約 1%）。

## 商店

- 第 3、6、9、12 日收盤後開店（`gameplay.stageDays`，最後一日不開）。每人三張王牌加兩張道具，價格只依稀有度：王牌 $500／$900／$1,400，道具 $150／$250／$400（`shop.price`）。
- 只能用現金付，購買會真正減少總身家；王牌與道具本身不計入總身家。
- 精打細算讓售價打八折，所有折扣合計最多 90%。
- 王牌滿 5 張時要換掉一張，舊牌以清單價 25% 回收（`shop.sellRate`）。啟動時驗證回收比例低於「1 − 最大折扣」，所以不可能低買高賣。道具替換不回收。
- 購買發生在收盤之後、隔天開盤之前；共同市場與新聞的種子序列不受購買影響。
