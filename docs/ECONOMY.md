# 經濟與歸零規則（V3.1）

所有金額為整數遊戲元。每人起手 $10,000。數值放在 `src/config/financial.json`、`src/config/allocation.json` 與 `src/data/finance.json`，畫面、電腦與模擬都讀同一套規則。

## 兩種錢

- **現金**：不受股市漲跌影響，之後可用來買王牌與道具（Phase 3 商店）。
- **股票**：跟著每日共同市場與新聞漲跌。
- **總身家 = 現金 + 股票。** 沒有借款、還款、利息、開辦費、收盤另付、定存或追繳。

## 每日配置

- 只有三種配置：全留現金（0%）、一半買股（50%）、全部買股（100%）。預設沿用前一天，第一天為一半買股。
- 配置在市場結果揭曉前與卡片一起鎖定，之後無法撤回。
- 調整配置只是現金與股票互換：股票目標 = ⌊總身家 × 比例⌋，沒有手續費，總身家不變。
- 股票最多跌到 $0，不會變成負值或欠款。

## 結算順序

1. 鎖定四人的配置與卡片。
2. 依配置換成股票與現金。
3. 卡片效果。
4. 共同市場：所有人同一個漲跌幅（`market_day`，目前 −3.5%～+4.5%，同日共用一個種子亂數）。
5. 新聞日套用新聞漲跌與護盾。
6. 收盤：總身家 ≤ 0 即歸零。

不同角色的損益差異只來自持股金額、卡片（之後是道具與王牌）以及新聞目標。

## 歸零與翻身

- 第一次歸零且還有後續交易日：拿 $1,000 翻身資金，不用還。手牌、護盾與預告清空，避免刻意歸零換資源。
- 第二次歸零或最後一日歸零：出局，可觀戰或查看個人結算。
- 沒有借款後，一般遊玩幾乎不會歸零（1,000 種子模擬中無人歸零），翻身規則保留給之後的倍率型道具與王牌。
