# 金融策略玩法

## 交易週期

玩家與三位電腦對手用同樣的初始本金開盤，預設 15 個交易日，交易無倒數。每日先領取到期定存及利息，再各抽一張卡；起手 2 張，第一日開盤另抽一張。手牌上限 5 張，當日最多用一張。滿手時可替換或放棄新卡。投資機會與符合資格的補給提供三張不同卡供選擇。

所有席位鎖定卡片和路線後，先處理卡片和節點，再結算每三日一次的虛構市場事件。競爭型個別事件可有不同目標，目標依開盤狀態決定。「融資稽核」會收緊最近融資領先席的當日追繳門檻，同名次適用相同條件。市場回報依持倉與避險計算，事件情報只給取得者，預告下一個仍可用來規劃的交易日事件。

## 策略與路線

每座設施掛在一日一列的共用分岔圖。穩健投資累積部位，股息依持倉帶來現金，定存鎖定部分現金換取後續利息；槓桿提高雙向損益並負擔費用與追繳。獲利了結、場外觀望、避險機構與研究中心提供降低曝險或提前規劃的選擇。卡片透過路線協同補強收益、流動性及保護。

穩健成長、現金與定存、避險搭配成長、卡片協同及高槓桿是可測試的策略。現階段以合併持倉簡化資產種類，讓選擇著重現金水位、槓桿與後續路線。三到五分鐘是產品目標，仍須真人遊玩驗證。

## 收盤

最後一日處理所有市場波動、利息、費用、風控與破產後，按有效席位的淨資產排名；同分並列。第一次破產的重整與提早出局規則見 [經濟與破產規則](ECONOMY.md)。結算提供逐日績效、資產回撤、交易明細與娛樂性稱號；稱號不影響能力。

新聞每三個交易日公布。同局優先抽未看過的消息，避免連續利空及三則連續利多，同類連續時降低機會，黑天鵝每局最多一次。
