## 自動化

執行 `npm run typecheck`、`npm test`、`npm run build`。新版有 18 項通過的 Vitest 測試。正式建置完成，Rollup 回報 Zod 套件註釋及延遲載入的 Phaser 區塊大小警告。主入口約 56 kB gzip，重大市場像素效果區塊約 331 kB gzip。

## 瀏覽器驗證

使用桌面 Chrome 158 的無頭模式，以正式建置測試 `/stock-summit/` 子路徑。以觸控模擬驗證手機，並從瀏覽器送出桌機滑鼠與鍵盤事件。主要互動區至少 44 px，測試的頁面及路線視窗無橫向捲動。

| 視窗 | 已驗證流程 |
| --- | --- |
| 320 × 640 | 開盤到第 15 日收盤、平倉明細、破產重整、提早出局、個人結算、返回觀戰至收盤 |
| 360 × 780 | 開盤、選卡、路線圖、選擇保存、確認首日交易及績效曲線更新 |
| 390 × 844 | 同上，另旋轉至 844 × 390 並確認仍保留卡片及路線選擇 |
| 430 × 932 | 開盤、選卡、路線圖、選擇保存、確認首日交易及績效曲線更新 |
| 1440 × 900 | 完整 15 日、左右鍵選路、空白鍵確認、略過動畫、市場像素效果、收盤分享及同種子重玩 |

驗收執行了 21 次滿手抽卡流程、4 次三選一、2 次有資產處分的強制平倉、2 次破產重整、2 次 Phaser 效果與 1 次出局後個人結算。當次測試未捕捉到瀏覽器例外。可在建置後重跑 `node scripts/verify-browser.mjs`，截圖位於本機 `test-results/v2/`。

## 尚待驗證

實機 Safari、Android 瀏覽器及部分較舊引擎仍待操作驗證。三到五分鐘單局節奏、策略是否有趣、穩健破產率和高槓桿的勝率差距仍需進一步觀察。GitHub Pages 正式部署由現有遠端工作流程處理。


## 60 則快訊與白話文案驗收

- 型別檢查、21 項 Vitest 測試及正式建置通過。建置仍回報 Zod 註釋與延遲載入的 Phaser 區塊尺寸警告。
- 以 1,000 個相同種子比較 9、30、60 則版本。市場及八種策略實測結果見 [平衡模擬](BALANCE.md)。
- Chrome 158 驗證 320、360、390、430px 及 1440px。320px 和桌機完成整局；另驗證 390px 動態卡片金額、320px 快訊實際損益、展開平倉及重整帳務、提早出局後觀戰，無瀏覽器例外。
- 手機畫面截圖保留於本機 `test-results/copy-before/` 及 `test-results/v2/`。實機 Safari、Android 及新人是否能在數秒內理解牌面，仍待真人操作驗證。
