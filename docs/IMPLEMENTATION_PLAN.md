# 實作與驗收
1. 初始化 Vite/TS/Phaser/Vitest、設定驗證、共用狀態與測試指令；建立首頁及選角。
2. 垂直切片：10 層測試圖、四角色、鍵盤、鏡頭、NPC 可完整到頂、排名、結算與重玩。測試碰撞、梯子、跳躍與路徑。
3. 事件與卡片：建立 JSON、統一效果引擎、目標解析、seed、新聞、背包及 NPC 用卡。測試全體/單人/兩人/排名目標、護盾、邊界、暫停及效果期限。
4. 擴為五區約40層，完善 HUD、小地圖、角色像素造型與特效；調整節奏，圖鑑與設定。
5. 驗收：四角色能力一致；每種選角可開局；NPC 不瞬移作弊且可到頂；事件及卡片新增既有效果不改 TS；位移不出界不卡牆；暫停不消耗時間；重玩無重複事件；逾時與登頂均正確結算；繁中 UI 無遮擋。執行 typecheck/test/build，實際瀏覽器遊玩並記錄未驗證事項。提交 README 與變更摘要。
