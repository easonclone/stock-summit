# 改版盤點

遠端 `main` 的 `2d7ce59` 已有 15 日、4 路同步回合、相鄰分岔生成器、共用效果與每三日的虛構事件。原本機 `main` 停在 `9e06b9b`，尚未提交的即時競速版本已保存在 `codex/stock-summit-v2` 的 `f8adee2`。本改版分支自遠端同步回合版建立。

| 原同步回合版 | 財務版遷移方式 |
| --- | --- |
| `Run` 依序落實電腦用卡，後續電腦會看到部分已改動狀態 | 保留可獨立執行的回合入口，先鎖定所有決策及干預目標，再分階段結算 |
| `node-map.ts` 相鄰、不交叉且可達 | 沿用生成與驗證，改善單線與節點分布 |
| 層數、鈔票加權、Mountain Track | 改用資產負債帳本及正式收盤淨資產，完成新介面後移除舊場景與物理資料 |
| `effectIds`、目標選擇、種子亂數 | 保留共用效果模型與目標規則，替換財務效果，分離市場、盤中波動、抽卡及決策亂數 |
| 角色資料、像素繪製、合成音效 | 保留四位角色和像素素材，改以交易席位呈現 |
| 靜態建置及 GitHub Pages 工作流程 | 沿用相對建置路徑與既有工作流程 |

## 改版前基準

在遠端同步回合版上重新執行型別檢查、22 項測試與正式建置，均完成。建置記錄 Zod 註釋與 Phaser 區塊尺寸警告。以種子 1–300、每位角色輪替、普通電腦對手重測，測試玩家均未主動用卡。勝率採舊引擎含同分判定的單一冠軍。

| 路線策略 | 勝場／300 | 平均收盤分數（層數含鈔票加成） |
| --- | ---: | ---: |
| 固定最左 | 29 | 25.89 |
| 隨機 | 15 | 25.41 |
| 節點效用及前瞻一步 | 33 | 28.29 |

這組數值只作為舊版可重現基準。新版比較以淨資產及破產風險為單位。
