# UI 與美術
復古 16-bit 像素風 × 金融交易終端。遊戲畫布 16:9，建議邏輯解析度 960×540，等比縮放，像素素材 nearest-neighbor；繁中介面使用易讀字型。深藍 #182333、面板 #283B4F、金色 #EBC56D。台股預設紅漲綠跌，搭配箭頭及文字；設定可切國際慣例。先使用自製程式化像素素材，避免外部素材授權問題，保留替換介面。
頁面：首頁（開始、說明、圖鑑、設定）；選角（四人頭像、選中 PLAYER、其餘 NPC）；正式遊戲；結算（返回、新賽道、再玩一局）。

正式畫面（回合制）：上方顯示交易日 x/15、名次、總分與盤勢。桌機左側為山路像素畫面與最近事件，右側為路線圖；手機改為直向堆疊，路線圖可捲動，確認列固定在畫面底部。路線圖由下往上排列，每列一個交易日：可前往的節點發光，已走過的節點與連線以金色標示，四位選手以色塊標在所在節點。下方為卡欄、鈔票與收盤加成、四人排名。新聞框顯示市場事件 2–3 秒並標示虛構模擬。角色上方姓名，玩家有額外箭頭。事件效果須有短動畫、位移方向與文字；可關閉震動。

鍵盤：←/→（或 A/D）切換可選節點、Enter 或空白鍵確認進場、1/2/3 用卡；所有操作也可點按。台股預設紅漲綠跌，設定可切國際慣例。結算表優先顯示實際層數、收集金額、鈔票加成與最終分數。
