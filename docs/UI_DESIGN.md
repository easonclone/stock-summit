# UI 與美術
復古 16-bit 像素風 × 金融交易終端。遊戲畫布 16:9，建議邏輯解析度 960×540，等比縮放，像素素材 nearest-neighbor；繁中介面使用易讀字型。深藍 #182333、面板 #283B4F、金色 #EBC56D。台股預設紅漲綠跌，搭配箭頭及文字；設定可切國際慣例。先使用自製程式化像素素材，避免外部素材授權問題，保留替換介面。
頁面：首頁（開始、說明、圖鑑、設定）；選角（四人頭像、選中 PLAYER、其餘 NPC）；起跑 3/2/1/開盤；正式遊戲；暫停；登頂與結算（返回、重玩）。
正式畫面：左側約 78% 為遊戲區，右側約 22% 為排名、小地圖與最近三筆事件。上方時間、進度、排名；中央上方新聞條顯示影響對象及效果 2–3 秒；底部三格卡片、快捷鍵與下次事件倒數。資訊不得遮擋角色與必要地形。角色上方姓名，玩家有額外箭頭。事件效果須有短動畫、位移方向、文字；可關閉震動。四位角色同一碰撞盒，潘大帥寬肩、游游休閒黃衣、老伯灰髮眼鏡、張婷馬尾粉紫外套為暫定造型。鍵盤焦點、暫停及視窗縮放須正常。
