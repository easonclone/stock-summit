# 交易終端介面

## 攻防命中回饋

演出全部讀取結算紀錄，數字皆為實際金額，不改變任何帳務或卡片效果。

- 命中：攻擊者道具名稱短暫亮起，目標局部閃光並跳出傷害浮字，財富條立即下降，延遲傷害條約 0.38 秒後跟上，搭配命中音效。
- 分級（傷害占目標開盤身家）：3% 以下輕擊、3–8% 一般、8–15%「強力一擊」、15% 以上「重擊」。強力與重擊有較大數字、像素爆點、短震動與重音效；不使用「爆擊」字樣。分級只影響畫面與聲音。
- 事件：護盾格擋（藍光、顯示實際抵銷金額）、破盾（碎片）、反擊鏡（浮字在原攻擊者身上）、資金掠奪（目標扣、攻擊者加、金幣飛行）、市場漲跌（不同浮字、無命中效果）、未命中（「未命中・對手沒有股票」等，無成功特效）。股市大混戰同一瞬間打中多人，道具名只亮一次。
- 王牌連鎖：玩家王牌依序亮起並顯示各自實際貢獻，音高逐步上升，上方顯示累計「王牌 ×N」；電腦的王牌合計為一個數字。
- 財富條分三層：即時、延遲傷害、空底；四人共用同一金額量尺，單次演出中不重新縮放。
- 節奏：事件並行，整體上限約 1.6 秒；交易按鈕不等待演出。音效經壓縮器並限制同時數量，遵守靜音設定。
- 手機：浮字依視窗寬度縮放，不攔截點擊。減少動態：無震動、縮放與粒子，只留靜態數字與必要的財富條更新，不增加等待。

## V3.2 像素競技場

四席共用財富條量尺，刻度代表初始本金。每次結算用同一尺度呈現前後金額。第一名顯示皇冠，玩家席以邊框標示。受擊、反擊、護盾與名次變動同步回饋，主要效果在約半秒內播放。

先選配置，再看王牌與道具。選好單體攻擊道具後，直接點對手席位。準星和底部操作欄會顯示選中的人，重點一次即可取消。目標試算使用目前的公開資產，股價結算後才計算實際金額。一般回合的換日字幕約 1 秒，抽卡約 0.3 秒，重大新聞仍可調整速度或略過。

## V3.1 前期節奏與換日

交易欄每天標示下一次商店，遇到同日有新聞便一併提示。開局三張道具中包含收益和防禦各一張，玩家每天可使用一張。第 2 日起，免費道具直接出現在道具區。滿四張時，同一區塊展開替換與放棄選項。

上一日的結算、新聞、待領獎勵與商店處理完後，呈現一次 1.4 秒的 `DAY 02` 開盤字幕。點擊任何操作即可略過，減少動態設定會直接顯示交易畫面。抽到的道具保留一行名稱和效果，普通抽卡以 420 毫秒亮框及現有短音效回饋。


以附圖的深色交易終端、四席位、績效線與卡片配置為參考。主色為深藍與金色，程式化像素角色保留原外觀，漲跌同時用箭頭及正負數呈現。預設台股配色，可切換國際配色。

- 視覺優先順序：角色競技 → 總身家與排名 → 今天買多少股票 → 道具 → 王牌 → 新聞。
- 手機由上而下：A 日期與市場快訊跑馬燈、B 四人像素競技場、C 總身家／排名／現金／股票與現金股票雙色條、D 條件式狀態標籤、前一日結算分項、E ①「今天買多少股票？」三個配置按鈕（各附雙色條）與預覽、F ②「要不要用道具？」四格道具、G「我的王牌」五格、H 固定「開始交易」列。桌面左欄為競技場、身家與前一日結算，右欄為配置、道具與王牌。
- 主畫面只常駐總身家、排名、現金與股票。待命護盾與小道消息得知的新聞方向只在成立時以標籤顯示；沒有借款、利息、比率或財務明細視窗，也沒有路線圖。走勢圖為一個快開視窗。
- 前一日結算直接列出實際結算連鎖：今日股市、新聞、每張發動的王牌（金色）與道具、護盾、狙擊、倍率上限，依結算順序排列，加總必等於實際身家變化。發動兩張以上時標「連招 ×N」，有動畫時逐行出現，發動的王牌在王牌列依序放大閃光。
- 卡片牌面只放像素圖示、名稱、主要數值、一句話與稀有度方點。王牌用金色雙線圓角框，道具用頂端虛線的票券框。道具另標今天能不能用與原因（例如「今天沒有股票，用了不會多賺」）；選中後浮起，下方說明今天用了會怎樣。點王牌或「完整說明」開啟詳情。
- 配置預覽顯示換倉後的現金與股票金額，以及今天大約可能賺賠的範圍（估計）；零值隱藏。
- 四位角色有閒置、思考、下單、獲利跳躍、虧損垂頭、護盾、被狙擊、追繳、破產、重整、超車與勝利動作，全部依當日實際結算判定；頭頂冒出實際身家變化與護盾擋下金額。動作為 CSS 動畫，減少動態時關閉。
- 新聞日播放「市場事件劇場」（RPG 對話）：場景轉場與專屬音效 → 主播或記者逐字說明 → 一至兩位角色依實際結算說出情境台詞 → 市場動畫、護盾與連招浮字、Phaser 粒子 → 四人實際新聞損益、當日身家變化與名次變化 → 回到競技場。一般新聞只播一句主播與一位角色；重大與黑天鵝才播完整段落，黑天鵝加紅色警報閃光與畫面撕裂。最後一日另播收盤冠軍。
- 劇場全程自動推進，不必逐句點擊；點對話框或按 Enter／Space 先補完當前句、再進下一句，Esc 或「略過演出」立即結束。設定可選完整 RPG 演出、快速演出或略過演出；減少動態時文字直接顯示、不自動跳頁、不播動畫。劇場只讀已完成的結算紀錄，略過或任何時點中斷都不影響結果；當日若先觸發破產重整，重整決定後才播。
- 新手引導：開局說明「你有 $10,000。買股票可能賺錢，也可能賠錢。15 天後，最有錢的人獲勝！」；前三日顯示「買多少股票 → 用道具（可不用）→ 開始交易」步驟條；第一天提示配置、商店日提示「收盤後商店開門，全部買股就沒錢逛商店」，之後依序提示王牌與道具、第一次遇到利空時說明現金不受影響、護盾與歸零首次出現時各一句。可逐則「知道了」、整個「略過教學」，或於設定重新開啟；記錄存在瀏覽器，讀寫失敗時照常顯示。
- 績效圖以實際收盤報酬率繪製，0% 表示初始本金。虛線標記市場或財務事件，方點標記平倉與破產。
- 可從路線圖檢視當前、未來與公開歷史選擇。投資與卡片在確認前可反覆選擇，路線圖關閉後保留兩者。滿手抽卡及選卡用可鍵盤操作的原生對話框。
- 破產、平倉、追繳由獨立視窗呈現，逐項列出損益、清償、殘債與影響。重整需由玩家接受，出局可繼續觀戰或查看個人結算。

## 白話操作及訊息優先順序

選牌先看建議搭配、目前能否使用及原因；選路後依同一引擎試算顯示額外收益、少賠多少、拿到多少現金或要付多少。詳細百分比及規則可自行展開。配置預覽先顯示現金、股票與可能賺賠，略去無關的零值。快訊列出本人實際損益與護盾擋掉的金額，危機先解釋發生什麼，再展開帳目。

## 商店（Phase 3）

- 商店是不可按 Esc 關閉的對話框，標題「第 N 日收盤・商店」，頂端顯示現金與王牌／道具格數；第一次逛時多一句「只能用現金買」的說明。
- 五張商品用和手牌相同的牌面，牌下是價格（打折時舊價刪除線）與狀態：買得起／差 $X／要換掉一張／已經有了／已買下。已買下變灰，現金不夠的半透明。
- 點商品後下方顯示完整說明；滿格時出現「換掉 ○○」列表，王牌附回收金額。底部固定「離開商店」與「用 $X 買下」，不能買時按鈕停用並說明原因。
