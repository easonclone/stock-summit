# 交易終端介面

以附圖的深色交易終端、四席位、績效線與卡片配置為參考。主色為深藍與金色，程式化像素角色保留原外觀，漲跌同時用箭頭及正負數呈現。預設台股配色，可切換國際配色。

- 視覺優先順序：角色競技 → 總身家與排名 → 手牌 → 投資選擇 → 新聞 → 財務細節。
- 手機由上而下：A 日期與市場快訊跑馬燈、B 四人像素競技場、C 總身家／總報酬／排名／手上現金、D 條件式狀態標籤、前一日結算分項、E 橫向滑動手牌、F 投資選項、G 固定確認列。桌面左欄為競技場與身家，右欄為手牌與投資。
- 主畫面只常駐總身家、總報酬、排名、手上現金。股票市值、定存及到期日、欠款合計（融資＋救命貸款）、收盤另付、護盾數、布局剩餘天數、已知新聞及風險警示只在成立時以標籤顯示；不再顯示「交易正常／無融資／無避險」等零值字樣。部位／淨資產、融資比率、個別欠款、追繳門檻與完整資產表放在「財務明細」視窗，走勢圖與路線圖各為一個快開視窗。
- 前一日結算分項由實際結算紀錄拆出：投資損益、股息與利息、市場新聞、費用，分項加總必等於實際身家變化；卡片貢獻、護盾擋下金額與連招次數只作附註，不重複加總。
- 手牌牌面：像素圖示、名稱、主要數值、一句白話、今天可否使用（含不可用原因或可用路線）、持續天數。選中後浮起並高亮，可出卡路線加虛框、會連招的路線加金框；未接上連招的卡仍標「可用」，不會呈現為不能用。「完整規則」開啟卡片詳情視窗。
- 投資選項顯示估計可能賺、可能賠、出資、借款或賣出，以及槓桿、可能追繳、連招等標籤；定存顯示日息與到期日；零值隱藏。範圍一律標示為估計，費用與利率在「費用與細節」展開。
- 四位角色有閒置、思考、下單、獲利跳躍、虧損垂頭、護盾、被狙擊、追繳、破產、重整、超車與勝利動作，全部依當日實際結算判定；頭頂冒出實際身家變化與護盾擋下金額。動作為 CSS 動畫，減少動態時關閉。
- 新聞依嚴重度分級演出：一般為跑馬燈燈號閃動；重大加上競技場閃框、Phaser 像素漲跌粒子；極端另加短暫全螢幕快訊，逐人列出實際新聞損益與護盾，按鈕、Enter、Esc 或 2.6 秒後自動結束。音效依序挑選追繳、極端、護盾、連招、名次上升或漲跌各一種。
- 新手引導：前三日顯示「選卡 → 選投資 → 下單 → 看結果」步驟條；槓桿、定存、護盾、追繳、破產首次出現時各給一句提示。可逐則「知道了」、整個「略過教學」，或於設定重新開啟；記錄存在瀏覽器，讀寫失敗時照常顯示。
- 績效圖以實際收盤報酬率繪製，0% 表示初始本金。虛線標記市場或財務事件，方點標記平倉與破產。
- 可從路線圖檢視當前、未來與公開歷史選擇。投資與卡片在確認前可反覆選擇，路線圖關閉後保留兩者。滿手抽卡及選卡用可鍵盤操作的原生對話框。
- 破產、平倉、追繳由獨立視窗呈現，逐項列出損益、清償、殘債與影響。重整需由玩家接受，出局可繼續觀戰或查看個人結算。

## 白話操作及訊息優先順序

選牌先看建議搭配、目前能否使用及原因；選路後依同一引擎試算顯示額外收益、少賠多少、拿到多少現金或要付多少。詳細百分比及規則可自行展開。下單預覽先顯示出錢、借錢與可能賺賠，略去無關的零值。快訊列出本人實際損益與護盾擋掉的金額，危機先解釋發生什麼，再展開帳目。
