## 假設（待後續階段驗證）

1. **共同市場範圍** −3.5%～+4.5%（平均每日約 +0.5%）。沿用舊新聞的漲跌幅（平均每則約 −2%）。
2. **配置在卡片之前換倉。** 卡片效果作用在換倉後的股票上。
3. **翻身資金 $1,000** 依規格設定。翻身時清空手牌與護盾，避免故意歸零換資源。
4. **電腦打法** 仍全部用 `mixed`：平時全部買股，知道利空就留現金，有新聞但沒情報時降一級。規格要求的流派（現金奶牛、股息、賭神、防禦、道具）等王牌上線後再做。
5. **情報與公開新聞池。** 前一則利空後，排程會優先挑利多，所以公開候選池可能全部偏多，預覽範圍會因此只顯示上漲。這會讓配置有接近無風險的時機，列為 Phase 2 新聞重分類的待修項目。

## 1,000 種子模擬（V3.1 Phase 1）

玩家席使用下列打法，三名電腦都用 `mixed`。「勝率」是四人局奪冠比例，並列平分。

| 打法 | 勝率 | 平均總身家 | P10／P50／P90 | 歸零率 |
|---|---|---|---|---|
| random | 0.009 | $13,324 | 10,073／13,163／16,719 | 0 |
| 全留現金 cash | 0 | $11,022 | 10,280／10,946／11,863 | 0 |
| 一半買股 half | 0.005 | $14,566 | 12,475／14,442／16,743 | 0 |
| 全部買股 all | 0.174 | $18,483 | 13,430／18,073／23,667 | 0 |
| mixed | 0.219 | $19,255 | 14,756／18,984／24,124 | 0 |
| combo | 0.043 | $17,431 | 14,140／17,274／21,121 | 0 |
| hedge | 0.056 | $17,574 | 14,387／17,242／21,439 | 0 |

角色勝率（四席都用 mixed）：潘大帥 0.252、尤尤 0.259、老伯 0.243、張婷 0.246。四位角色仍然公平。

### 判讀

- **全部買股是目前的最佳固定打法**，全留現金不可能贏。原因有兩個：現金還沒有用途（商店在 Phase 3），而且舊卡片的加成都按股票金額計算。這正是規格第 22 節要防的情況，必須在 Phase 2（道具、王牌）與 Phase 3（商店）解決。Phase 1 沒有硬調市場參數來掩蓋。
- 沒有借款後，所有打法的歸零率都是 0，最大單局回撤 P90 約 21%（全部買股）。
- 舊版（V3.0）基準是穩健 0.277、槓桿 0.394、槓桿破產 0.171。槓桿與破產套利這類問題已經不存在。
