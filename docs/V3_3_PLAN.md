# V3.3 自由出牌與資產取捨

- 開盤先處理每日抽牌。每日商店兩個貨位，每件只能買一次，使用換倉前現金。現金贈送道具與招待券由抽牌供應。回收價低於折抵後同一王牌的最低售價，避免循環買賣。
- 立即與防禦牌點擊就消耗，道具發放在原牌讓出格子後處理。生成道具排除其他生成牌。每日最多部署一張，待命護盾和反擊鏡合計最多兩張。含立即、防禦及命中的行動在內，每天最多發動六張。
- 股票配置與最多兩張行動牌一併鎖定。共用市場、新聞、王牌及股價防禦先結算，接著是角色攻擊、反擊和其他現金收益。雙重打擊只能修飾下一張攻擊，沒有命中時兩張都保留。每對攻守組合一天最多一次直接命中，直接損失合計最多開盤身家的 25%。反擊單次最多 $1,500，群攻和破盾不觸發反擊。
- 市場測試參數為 −8%～+9%，新聞及 5 倍股票收益上限沿用。現金奶牛維持 2%、每日最多 $300，和銀行大戶合計每日最多 $600。印鈔機每張 $200、每日最多 $600。新數值仍待平衡驗證。
