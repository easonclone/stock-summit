# V3.4 流派與王牌

| 流派 | 構築方向 | 新王牌 |
| --- | --- | --- |
| 股票爆發 | 透過股票獲利加成與倍率爭取大漲，承受市場下跌與股票攻擊 | 沿用現有王牌 |
| 現金經濟 | 留現金購物，搭配現金收益或折扣 | VIP會員 |
| 股息持有 | 維持持股，靠股息與持續加成累積收入 | 股息再投資、耐心投資人 |
| 攻擊掠奪 | 用攻擊道具壓制對手，靠命中取得賞金或補給 | 賞金獵人、軍火商、空頭獵人 |
| 防禦反擊 | 在市場下跌或被攻擊時減少損失，利用反擊及保險增加報酬 | 保險大亨、復仇者、不動如山 |
| 抽牌連招 | 在手牌容量和每日上限內，規劃抽牌、使用和回收 | 魔術師、連招大師、回收商 |

## 共用結算

- 賞金獵人以開盤時的排名為準，並列第一皆有效。軍火商以實際命中的攻擊道具張數計算，群攻只算一張。空頭獵人提高單體股票傷害，仍套用原有直接攻擊上限。
- 復仇者與反擊鏡同時待命時，由反擊鏡處理當日首次有效單體攻擊。反擊不會再引發反擊。保險大亨按實際擋下的市場損失計算，保險金直接進現金。
- 魔術師發的道具不會再生成道具。連招大師只計算實際消耗的牌。回收商每天只付一次，拒收贈牌或換掉舊道具都有效。收盤後處理的贈牌回收計入當時現金與個人紀錄。
- VIP會員返還第一筆購物實付金額的一部分，玩家須先付完整價格。首次購買發生在王牌商店時，最低價格保證返現後仍高於換出該王牌的金額。
- 股息再投資根據股息王或股息加倍爽實際入帳的股息加成。耐心投資人從達到連續持股門檻的當天開始增加股票獲利，空手會重算。

效果數值維護於 `src/data/finance.json`，稀有度和效果引用維護於 `src/data/cards.json`。普通與稀有王牌沿用各自的共用售價。玩家和電腦共用出牌、購物及結算，電腦依持有王牌與已公開資訊估算搭配價值。

新王牌的售價回收速度、各流派競爭力及實際遊玩手感仍待驗證。

## 風險獻祭流

血色契約讓單體股票攻擊可以指定自己，按原攻擊比例扣股票。其餘獻祭先扣現金再扣股票。獻祭每日一次，至少保留 $1 身家，成本不受護盾或減傷影響。禁忌交易在出牌時扣款，行動獻祭在股價結算後扣款。即使對手的攻擊上限已用完，只要已支付成本，獻祭仍生效並消耗道具。

獻祭對對手的傷害先扣股票再扣現金，套用既有直接攻擊的次數、傷害上限和不動如山。痛苦轉移只加強獻祭群攻。末日使者按鎖定前公開排名選擇最高的一位對手，並列時依競技場排序。獻祭攻擊不觸發反擊，也不能用雙重打擊放大。

逆境狂人與獻祭衍生的攻擊賞金、道具現金獎勵共用同一限額，合計最多返還成本減 $1。浴火重生只影響隔天的股票獲利，仍受既有股票獲利上限限制。三張圖集沿用既有 ImageGen 美術提示，補齊前一批 12 張王牌與新卡的專屬插畫。競技場背景改為低對比網格與已結算的大盤開收盤柱。
